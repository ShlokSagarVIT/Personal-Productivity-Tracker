# Project Statement

## Project Title

Personal Productivity Tracker

## Problem Statement

Students and working individuals often have difficulty managing their daily tasks and monitoring how effectively they spend their time. Without a structured system, it can be difficult to track completed tasks, pending work, and focused study or work time.

The Personal Productivity Tracker provides a simple Java-based solution for managing tasks, recording focus sessions, analyzing productivity, and generating productivity reports.

## Scope of the Project

The project focuses on personal productivity management. It allows users to create and manage tasks, record focused work sessions, analyze task completion and focus time, calculate a productivity score, and generate productivity reports.

The application uses Java for the main application logic and SQLite for persistent data storage.

## Target Users

- Students
- Working professionals
- Individuals who want to organize their daily tasks
- Users who want to monitor their focused work time

## High-Level Features

### 1. Task Management

- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Set task priority
- Set category
- Set deadline
- Track task status

### 2. Focus Time Tracking

- Record focus sessions
- Store activity details
- Record start and end times
- Store focus duration
- Calculate total focus time

### 3. Productivity Analytics

- Calculate completed tasks
- Calculate pending tasks
- Calculate task completion rate
- Calculate total focus time
- Calculate productivity score

### 4. Productivity Reports

- Generate productivity summaries
- Display task statistics
- Display completion rate
- Display total focus time
- Display productivity score

## Non-Functional Requirements

1. **Usability** – The application should have a simple and understandable interface.

2. **Performance** – Task operations and productivity calculations should execute efficiently.

3. **Reliability** – The application should handle database and input errors without unexpected termination.

4. **Maintainability** – The application should use modular classes and a proper package structure.

5. **Error Handling** – Invalid inputs and database errors should be detected and handled appropriately.

6. **Resource Efficiency** – The application should use system resources efficiently and close database connections after use.

## Technical Requirements

- Java Development Kit (JDK) 17 or higher
- Maven
- SQLite
- JDBC
- GitHub for version control
